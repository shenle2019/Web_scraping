01 eval 函数验证（Python 侧）
================================================================

[1] 课件表达式 '1 + 2 * 3 / 4 + (5 ** 2 - 8)'
    直接打印            : 1 + 2 * 3 / 4 + (5 ** 2 - 8)
    eval(exp)           : 19.5
    [PASS] eval 结果与直接求值一致 == 19.5

[2] 作用域行为：eval 默认使用调用处的 globals/locals
    eval('x * y + math.sqrt(16)') = 204.0
    [PASS] eval 可见当前作用域变量与模块 —— 这就是混淆代码能跑通的原因
    exec('q = x * 2') 后 q = 20
    [PASS] Python 分工：eval=表达式求值 / exec=语句执行

[3] 逆向视角：字符串形式的代码对'明文搜索'隐身
    源码中的字符串     : 'sum([i * i for i in range(5)])'
    运行时实际结果     : 30 （0^2+1^2+2^2+3^2+4^2）
    [PASS] 静态看只是数据，动态求值才现形 —— 对应 JS 侧 hook eval 的动机

结论：eval 是'代码即数据'的入口；JS 逆向中网站用它藏算法，
      对付它的手段是在 eval/Function 处下 hook 打印入参（见 JS 侧验证与 Playwright 实战）。
