## 一、逆向为什么先得看懂 Java

- 反编译 apk 后拿到的是 dex 字节码，jadx 把它还原成 Java 代码。看不懂 Java 逻辑，加密函数摆在眼前也读不动。
- 这三天 Java 的目标不是"会写"，是"能看懂"。难点部分可以让 AI 给出等价实现，自己负责校对和调整。
- Java 是**编译型**语言（区别于 python 的解释型）：源代码必须先编译，执行的是编译产物，不是源码。

## 二、Java 三大体系

| 体系 | 内容 | 与逆向的关系 |
|---|---|---|
| Java SE | 基础语法、面向对象、并发、网络 | **必学**，安卓开发 = Java SE + 安卓 SDK |
| Java EE | Java Web，Spring / SpringBoot / SpringCloud | 无关，占 Java 就业 90% 但逆向用不到 |
| Java ME | 早期功能机开发标准 | 早已废弃 |

## 三、JDK / JRE / JVM 三层包含关系

向下包含：**JDK ⊃ JRE ⊃ JVM**

- **JVM**：Java 虚拟机，字节码的唯一执行场所，`.class` 离开它就跑不了。
- **JRE**：JVM + 类库，只运行 Java 应用时装它够用。
- **JDK**：JRE + 开发工具（`javac`、`jar` 等），做开发必须装。
- 现实里绝大多数人图省事直接装 JDK。课件统一用 **jdk1.8（java8）**——国内八成以上的 Java 项目仍在 jdk8。

## 四、编译执行流程与"一次编译，处处运行"的真相

三步走：

1. 写源码 `HelloWorld.java`
2. 编译：`javac HelloWorld.java` → 产出字节码 `HelloWorld.class`
3. 执行：`java HelloWorld`（不用带 `.class` 后缀）

字节码的常见形态：`.class` / `jar` / `war`，安卓侧是 **dex**。共同点是——它们都不是操作系统能直接执行的文件，必须由 JVM 加载。

跨平台的来源就是这层"中间态"：源码编译成字节码，各平台装各自的 JVM，同一份字节码在 win/mac/linux 都能跑。

| 语言 | 编译产物 | 跨平台方式 |
|---|---|---|
| C / C++ | 平台相关的可执行文件（.exe 等） | 不跨平台，在哪编就在哪跑，装完即用 |
| Go | 可执行文件，但支持**跨平台编译** | win 上能编出 linux/mac 的产物 |
| Java | 字节码（中间态） | 各平台装各自的 JVM |
| Python / Node / PHP | 不编译，直接跑源码 | 各平台装各自的解释器，天然跨平台 |

逆向视角的价值：`.class`/`.dex` 保留了类名、方法名、字符串常量等元信息，这才让 jadx 有东西可还原。也正因为如此，`jar`/`dex` 都能被反编译软件粗略还原成 Java 源码——和真实源码会有出入，但逻辑一致。

## 六、第一个程序与文件/类命名硬规则

```java
public class HelloWorld {
    public static void main(String[] args) {
        System.out.println("hello world");
    }
}
```

文件名规则三条（写代码和读反编译工程都会撞上）：

1. 一个文件里**最多一个 public 类**，且**文件名必须与该 public 类名完全一致**。
2. 文件里可以有多个类，但除 public 类外，其余类不能加 public。
3. 若文件里**没有** public 类，文件名可以随意。

代码包里的 `ZZ.java` 就是活例子：

```java
class YY {
}
public class ZZ {
}
```

文件名取自 public 类 `ZZ`，`YY` 只能保持默认修饰。

命名习惯：类名首字母大写驼峰（`HelloWorld`、`UserInfo`、`PersonApplication`），变量也用驼峰——这点和 python 的"类驼峰、变量下划线"不同。

入口固定形态：`public static void main(String[] args)`，`static`、`void`、字符串数组参数缺一不可，否则 JVM 找不到入口。

课堂上问过的一个对照：

- `main` 是**硬性入口**，Java 没有它根本运行不了。
- `if __name__ == '__main__':` 是**约定**，python 作为解释型语言可以从任意位置开始执行。

## 七、类与成员的修饰符

类修饰符只有两种：`public` 和 `default`（不写）。

成员（变量、方法）四档：

| 修饰符 | 可见范围 |
|---|---|
| `public` | 所有其他类都能用 |
| `private` | 只在当前类内 |
| `protected` | 当前包下的类（课件口径） |
| `default`（不写） | 默认 |

成员前面加 `static` = **静态成员**，属于类，不用实例化，`类名.方法()` 直接调；不加 `static` = **对象成员**，必须先 `new` 出对象。

`void` 表示方法无返回值；有返回值时把 `void` 换成返回类型。

课件的 `Main` / `Demo` 示例把四种调用方式演示齐了：

```java
public static String name = "彭于晏";      // 本类静态变量
Demo.add(3, 4);                            // 调别的类的静态方法（类比 python 的类方法）
System.out.println(Demo.age);              // 读别的类的 public 静态变量
Demo d = new Demo();
d.test();                                  // 调对象方法，必须先实例化
```

读反编译代码时的经验补充：加密函数大量以 `static` 工具方法的形式出现（`XxxUtils.encrypt(str)`），调用点直接写类名，不需要 new——知道 `static` 的语义才看得懂这种调用。

## 八、注释三种

- 单行 `//`，快捷键 `Ctrl + /`
- 块注释 `/* */`，可换行，快捷键 `Ctrl + Shift + /`（取消注释 `Ctrl + Shift + \`）
- 文档注释 `/** */`，用在类/方法/变量上，可带 `@param`、`@return`，鼠标悬停会显示

反编译产物里 javadoc 通常已丢失，看到的是纯代码——所以读别人的反编译代码不能指望注释。

## 九、变量与常量

```java
String name = "justin";        // 变量，声明必须带类型，可重新赋值
final String HOBBY = "篮球";    // 常量，一次赋值不可改
```

`final` 的三种用途（课件都点到）：

- 修饰变量 → 常量，不可再赋值
- 修饰方法 → 子类可继承但**不可重写**
- 修饰类 → 不能被任何类继承

## 十、输入输出

```java
System.out.println("换行输出");
System.out.print("不换行输出");
System.out.printf("格式化输出：%s，年龄：%d%n", name, age);
```

- 格式化占位：`%s` 字符串、`%d` 整数、`%n` 换行。
- 输入用 `java.util.Scanner`：

```java
Scanner scanner = new Scanner(System.in);
String inputName = scanner.nextLine();            // 相当于 python 的 input
int score = Integer.valueOf(scanner.nextLine());  // 拿到的是字符串，要比较得转 int
```

`nextLine()` 取回的一定是 `String`，想当数字用必须显式转换——这就是强类型语言的日常摩擦，也是反编译代码里 `Integer.valueOf` / `parseInt` 满天飞的原因。

## 十一、条件与循环

- `if / else if / else`，逻辑运算符是 `&&` `||`（不是 `and` / `or`）
- `switch (score) { case 99: ... break; default: ... }`，漏写 `break` 会往下贯穿
- `while` / `do-while`（无条件先执行一次）/ `for (int i = 0; i < 10; i++)`
- **增强 for**：`for (String item : names)`，相当于 python 的 `for x in list`

`break` / `continue` 语义与其他语言一致。反编译里增强 for 常被还原成迭代器或下标循环，认出这两种等价写法很重要。

## 十二、数据类型总表

| 类别 | 类型 | 说明 |
|---|---|---|
| 整数 | `byte` | 1 字节 8 位，-128 ~ 127 |
| | `short` | 2 字节 16 位，-32768 ~ 32767 |
| | `int` | 4 字节 32 位，默认整数类型 |
| | `long` | 8 字节 64 位，字面量加 `L` |
| 小数 | `float` | 32 位单精度，字面量加 `f` |
| | `double` | 64 位双精度，字面量加 `d`（可省） |
| 字符 | `char` | 单引号，一个符号 |
| 字符串 | `String` | 双引号，多个字符 |
| 数组 | `int[]`、`String[]` | 定长，元素类型固定 |
| 布尔 | `boolean` | `true` / `false` |

字符与字符串的区别（课堂追问）：`String name = "lqz";` 双引号放多个字符；`char n = '刘';` 单引号只能放一个。`char` 在 Java 里是 16 位，汉字也能直接装进一个 char。

数组是**定长 + 类型固定**的容器，`String[] names = {"a", "b"}` 里塞不进数字，这和 python 的 list 完全不同。打印数组要用 `Arrays.toString(arr)`，直接 `println(arr)` 出来的是 `[B@1540e19d` 这种对象地址。

## 十三、核心考点：Java 的 byte 是有符号的

这是整份课件对逆向最有价值的一段。

| | 取值范围 |
|---|---|
| Python 的 bytes | **无符号** 0 ~ 255 |
| Java 的 byte | **有符号** -128 ~ 127 |

同一个 `"彭于晏"` 的 UTF-8 字节，两边打印出来长得完全不一样：

```
python: [229, 189, 173, 228, 186, 142, 230, 153, 143]
java  : [-27, -67, -83, -28, -70, -114, -26, -103, -113]
```

差值正好是 256。所以互转规则只有一句：**大于等于 0 原样保留，小于 0 加上 256**（反方向在 Java 里用 `(byte)` 强转让它溢出回负数）。

课件的还原函数思路：

```python
def java_arr_to_python_str(v1):
    buf = bytearray()
    for i in v1:
        if i < 0:
            i += 256
        buf.append(i)
    return buf.decode('utf-8')
```

另外两个必须记住的类型提升规则：

- 两个 `byte` 相加，结果**自动提升为 int**；要存回 byte 必须 `(byte)(a + b)` 强转，因为可能溢出。
- `byte b = 'A';` 是合法的：字符按 ASCII 存成 65，`System.out.println(b)` 打印 `65`（数字），`Integer.toBinaryString(b)` / `toHexString(b)` 可以看二进制和十六进制形态。

**逆向落点**：Java 加密函数（MD5、AES 的中间步骤、Base64 前后处理）几乎都以 `byte[]` 进出。把 hook 打印出来的 Java byte 数组直接丢给 python 的 `bytes(...)` 会报错，必须先把负数 +256 补齐。这一步不做，后面所有编码/解码都会歪。

## 十四、字符串与字节数组、字符数组的互转

```java
String v1 = "彭于晏";

byte[] v2 = v1.getBytes();            // 默认编码，课件机上是 UTF-8
byte[] v3 = v1.getBytes("GBK");       // 指定编码，方法需 throws Exception 或 try-catch

String s1 = new String(new byte[]{-27, -67, -83, -28, -70, -114, -26, -103, -113});
String s2 = new String(new byte[]{-59, -19, -45, -38, -22, -52}, "GBK");

char[] c = "彭于晏".toCharArray();      // 字符串 → 字符数组
String s3 = new String(c);             // 字符数组 → 字符串
```

坑点：`getBytes()` 不带参数时用的是**平台默认编码**。课件机默认 UTF-8，所以 `"彭于晏"` 得到 9 个负数字节；换成默认 GBK 的 Windows 机器上，同样一行代码会得到 6 个字节。逆向复现时一律显式写 `"UTF-8"` / `"GBK"`，别依赖默认值。

## 十五、String 常用方法速查

```java
String origin = "hello world 中国";

origin.charAt(13);              // '国'，按下标取字符
origin.length();                // 长度
origin.trim();                  // 去前后空白
origin.toLowerCase();           // 转小写（toUpperCase 转大写）
origin.split(" ");              // 按分隔符切，返回 String[]
origin.replace("h", "l");       // 替换
origin.substring(2, 6);         // 左闭右开，等价 python 的 [2:6]
origin.equals("hello world");   // 比较内容（不要用 ==）
origin.contains("中");          // 是否包含
origin.startsWith("a");         // 是否以某串开头
origin.concat("哈哈哈");        // 末尾追加
```

两个易错点：

- `substring(start, end)` 是**左闭右开**，和 python 切片一致。
- `split` 返回数组，直接 `println` 打印出的是对象地址，得用 `Arrays.toString()`。

字符串拼接的两种写法：

```java
String s = "hello" + "world" + "中国";   // 每次都产生新 String，循环里拼效率差

StringBuilder sb = new StringBuilder();  // 非线程安全，快
// StringBuffer sb = new StringBuffer(); // 线程安全
sb.append("hello").append(" ").append("world");
System.out.println(sb.toString());
```

反编译里看到 `sb.append(x).append(y).toString()` 的链式结构，基本可以断定源码用的是 `StringBuilder`。

## 十六、Python 与 Java 对照速查

| 概念 | Python | Java |
|---|---|---|
| 入口 | `if __name__ == '__main__':` | `public static void main(String[] args)` |
| 变量声明 | 无需类型 | `类型 名字 = 值` |
| 常量 | 无，靠约定大写 | `final` |
| 字符串切片 | `s[2:6]` | `s.substring(2, 6)` |
| 容器 | list 可变长、可混类型 | 数组定长、类型固定 |
| 遍历 | `for x in lst` | `for (T x : arr)` |
| 格式化 | f-string / `%` | `System.out.printf("%s%d")` |

| 字符串转字节 | `s.encode('utf-8')` | `s.getBytes("UTF-8")` |
| 字节转字符串 | `b.decode('utf-8')` | `new String(b, "UTF-8")` |
| 拼接 | `"".join()` / f-string | `StringBuilder.append` |
| 命名 | 类驼峰、变量下划线 | 类驼峰、变量也驼峰 |

## 十八、关键知识清单

- **JDK ⊃ JRE ⊃ JVM**；只运行装 JRE，做开发装 JDK，课件统一 jdk1.8。
- Java 跨平台的本质：编译产物是**字节码中间态**，靠各平台各自的 JVM 加载；C/C++ 产物是平台相关可执行文件，所以不跨平台。
- 编译执行三步：`javac X.java` → `X.class` → `java X`（运行时省略后缀）。
- 文件名必须与 public 类名完全一致，一个文件最多一个 public 类。
- 入口固定 `public static void main(String[] args)`，`static` / `void` / 字符串数组缺一不可。
- 成员修饰符：`public` 全开、`private` 本类、`protected` 同包、`default` 默认；`static` 属于类，不加属于对象，调用前必须 `new`。
- `final` 修饰变量→常量、方法→不可重写、类→不可继承。
- `Scanner.nextLine()` 返回字符串，参与数值运算要 `Integer.valueOf` 或 `parseInt`。
- 数组定长且类型固定，打印内容必须 `Arrays.toString()`。
- **Java `byte` 有符号（-128~127），Python `bytes` 无符号（0~255），互转规则是负数 +256**——逆向还原 byte[] 密文的第一步。
- 两个 `byte` 相加自动提升为 `int`，存回 byte 需 `(byte)` 强转。
- `getBytes()` / `new String(byte[])` 不带编码时依赖平台默认编码，逆向复现一律显式指定 `UTF-8` 或 `GBK`。
- `substring(start, end)` 左闭右开；`split` 返回数组；字符串比较用 `equals` 不用 `==`。
- 循环拼字符串用 `StringBuilder`，反编译中的 `sb.append(...).toString()` 就是它的痕迹。
- 增强 for `for (T x : arr)` 对应 python 的 `for x in lst`。
