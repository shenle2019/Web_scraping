## 二、ADB（Android Debug Bridge 安卓调试桥）

### 工具要点
- 谷歌官方开发者工具：电脑用命令行方式指挥手机
- 下载：developer.android.com platform-tools（最新版）；各平台历史版本 androidmtk.com
- 包内含 **adb** 和 **fastboot** 两个工具

### 版本选择（重要坑）
- 建议用 **30.0.5** 版本（win 用 `platform-tools_r30.0.5-windows`）
- 亲测：刷 Pixel 2XL 用高版本 adb 不成功；2XL 是 2017 年机型，需搭配稍老版本（猜测与机型年代有关）
- 刷完机之后做安卓开发，再用最新版即可

### 安装配置
- **win**：解压到（如）`D:\soft\platform-tools` → 该路径加入用户环境变量 Path → cmd 执行 `adb version` 验证
- **mac**：解压到 `~/soft/platform-tools` → `vi ~/.zprofile` 追加 `export PATH=${PATH}:/Users/名字/soft/platform-tools` → `source .zprofile` 生效
- **环境变量原理**：命令行任意路径能敲 adb，靠的是 Path 里登记的目录；多个同名工具时优先取 Path 靠前的；scrcpy 等软件自带 adb 容易冲突（不混用/改优先级）；用户变量只对当前用户，系统变量对所有用户

### 开启 USB 调试（新机必做）
- 设置 → 关于手机 → 连点"版本号" 7 次 → 开发者选项 → 开启 USB 调试
- 数据线连电脑后，手机弹窗选"永远允许"

### 常用命令（分类速查）
| 类别 | 常用命令 |
|---|---|
| 服务 | `adb devices`（查看设备）、`adb start-server` / `adb kill-server` |
| 文件 | `adb push 电脑路径 手机路径`、`adb pull 手机路径 电脑路径`（多设备加 `-s 设备id`） |
| 应用 | `adb install xx.apk`、`adb uninstall 包名`、`adb shell pm list packages [-e 关键字]` |
| 设备信息 | `adb shell getprop ro.product.cpu.abi`（armeabi-v7a=32位 / arm64-v8a=64位）、`getprop ro.product.model`、`getprop ro.build.version.release` |
| 进手机内部 | `adb shell`（内部即 Linux 环境；`su` 切 root 需已 root） |
| 其他 | `screencap` 截屏、`screenrecord` 录像、`input tap/swipe/text/keyevent` 模拟操作、`logcat` 日志、`reboot` 重启 |

## 三、刷机（Pixel 2XL → 官方 Android 11）

### 背景
- 买回来的手机系统版本杂（安卓 8/9/11）且没 root → **统一线刷官方 11 版本并 root**，作为逆向基线环境
- 参考博客：cnblogs.com/liuqingzheng/p/17462127.html

### 线刷流程要点
1. 谷歌官网下载工厂包（机型 taimen = Pixel 2XL）：`taimen-rp1a.201005.004.a1-factory-2f5c4987.zip`
2. 解压到（如）D 盘根目录，**管理员身份**开 cmd 进入该目录（确认有 `flash-all.bat`）
3. `adb reboot bootloader` 让手机进入 fastboot 模式
4. `fastboot devices` 验证连接——**没输出 = 安卓驱动没装好**（设备管理器里用配套驱动更新）
5. 执行 `flash-all.bat` 刷机（win；mac 对应 `flash-all.sh`），等待完成自动重启
6. 开机配置后重新打开 USB 调试

### 注意事项
- **刷机会清空手机全部数据**；不要拿其他机型刷这个包（刷不进去）
- `flash-all.bat` 会依次刷 bootloader、radio、image 镜像等

## 四、Root（Magisk 面具）

### 原理（一句话）
- `boot.img` 是手机引导镜像，本身不含 root 权限；**用 Magisk 修补 boot.img（注入 root 能力）→ 刷回手机 → 获得 root**

### 流程
1. 安装 Magisk apk 到手机（`adb install`；资料包 v26.4，课件演示 v26.1）
2. 解压工厂包里的 `image-*.zip`，取出 `boot.img`（本目录已解压好全套镜像）
3. `adb push boot.img /sdcard/Download` 推到手机
4. 手机打开 Magisk → 安装 → **修补一个文件** → 选 boot.img → 生成 `magisk_patched.img`
5. `adb pull` 把修补后的镜像拉回电脑
6. `adb reboot bootloader` → `fastboot flash boot magisk_patched.img` → `fastboot reboot`
7. 开机打开 Magisk 验证 root 生效（超级用户栏可点）

### 补充要点
- **可以跳过刷机直接 root**：找到与当前系统**同版本**的官方包，只修补其中 boot.img 刷入即可
- 卖家已 root 好的手机：刷机、root 都不用做
- Pixel 4XL 欧版/美版：只要解了 OEM 锁就能按此流程处理
- 其他 root 方案（如 TWRP recovery）不建议使用

## 五、Charles 抓包

### 工具选型
- Wireshark（开源、多协议）/ Fiddler（HTTP/HTTPS 跨平台）/ **Charles Proxy（课程主用：图形化、移动端抓包友好）** / Tcpdump（Linux 命令行）

### 安装
- mac：`Charles_4.5.6_xclient.info.dmg`；win：`charles-proxy-4.5.6-win64.msi`
- 打开后输入 sn 破解（课件提供三组 name/serial）

### 抓 HTTP 包
1. Charles：Proxy → Proxy Settings 确认端口
2. `Help → Local IP Address`（或 ipconfig/ifconfig）查电脑 IP（课件示例 192.168.1.173）
3. 手机/模拟器：WLAN → 长按当前网络 → 修改网络 → 手动代理 → 填电脑 IP + Charles 端口
4. 案例：**爱学生 app** 登录包——POST json 到 `/app/v1/patriarchLogin/1`（username/password 为明文字段，可直接 requests 复现）

### 抓 HTTPS 包（重点：装证书 + root）

**证书机制（核心理解点）**
- 手机上不装证书只能抓 http；https 需要把 Charles 根证书装进手机
- 安卓 7 以下：安装即生效
- **安卓 7 以上：证书装进的是"用户证书"区，app 默认不信任，必须迁成"系统证书"——需要 root + Magisk 刷 move cert 模块**
- 用户证书 vs 系统证书：用户证书是用户自行安装（个人身份验证/加密通信）；系统证书由系统或厂商预装（校验应用签名、SSL/TLS 通信）

**操作步骤**
1. 手机配好代理后，浏览器访问 `chls.pro/ssl` 下载证书
2. 设置 → 安全 → 加密与凭据 → 安装证书；在"信任的凭据"里可看用户/系统两个分区
3. `movecert-1.9-4.zip` push 到 `/sdcard/Download` → Magisk 刷入该模块 → 重启
4. 重启后证书从用户级迁移到系统级 → 可正常抓 https
5. 案例：**今日南川 app** 抓 https 包——登录接口（`api.cqliving.com/login.html`）带 `hashSign`、`pwd`（32 位 md5 形态）及请求头 `sign`、`t` 等参数，已见反爬签名痕迹，属后续课程深入点

## 关键知识清单（速查）

- 逆向五步：拿到包 → 抓包 → 反编译 → Hook 动态分析 → Python 复现
- 目标 app 别从华为/小米市场下（多渠道打包有差异）
- 刷老 Pixel 认准 adb 30.0.5；环境变量的意义 = 命令任意路径可用
- 刷机三部曲：`adb reboot bootloader` → `fastboot devices`（验证驱动）→ `flash-all.bat`
- `fastboot devices` 无输出 = 驱动问题 → 装 `usb_driver`
- Root 本质：Magisk 修补 boot.img → `fastboot flash boot magisk_patched.img`
- 安卓 7+ 抓 https 三件套：**root + 安装 Charles 证书（chls.pro/ssl）+ movecert 迁移到系统证书区**
- 不刷机直 root 法：同版本官方包修补 boot.img
- 抓包环境等式：手机代理指向"电脑 IP : Charles 端口"
