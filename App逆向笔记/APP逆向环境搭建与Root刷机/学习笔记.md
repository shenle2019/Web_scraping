## 二 逆向原理与核心概念

### 2.1 正向 vs 逆向流程

- 正向（安卓原生开发）：Java/C 代码 + 安卓框架 → 打包 APK（资源文件 / .dex / .so）
- 逆向：拿到 APK → 反编译 + Hook → 得到 Java/C 逻辑 → 读懂逻辑 → 用 Python 复现请求 → 获取数据

### 2.2 反编译与工具链（两条线）

- 反编译 dex（Java 层）：**apktool**（解出资源+smali，可重打包）、**JADX**（dex→Java，带分析导航）、JD-GUI（class→Java）
- 反编译 so（C 层）：**IDA**
- 课堂演示：装 JDK → 解压 jadx → 运行 `bin/jadx-gui` → 打开"爱学生"app → 搜索 `patriarchLogin` 定位登录逻辑
- 关键前提：jadx 运行必须有 JDK 环境（课件附 jdk-8u301 的 win exe 与 mac dmg）

### 2.3 Hook 概念

- 定义：运行时修改/替换目标 App 的函数实现来改变行为，不改源码
- 常见技术：Xposed 框架、Frida（运行时可注入 JS 脚本）、DLL 注入（需 root 权限）
- 逆向场景写 Hook 脚本的目的：**不是**改 App 逻辑做绕过破解，而是确认代码逻辑、查看参数和返回值

## 三 设备选型与准备

### 3.1 电脑

- mac/win 均可（课件推荐 win）；建议 i5、16G 内存以上

### 3.2 安卓设备（两条路线）

- **模拟器**（入门过渡）：win 用网易 mumu / 逍遥 / 夜神 / 雷电（用 3 版，不要 4 版，4 版后续抓包会出问题）；mac 用 mumu（不支持 m1）；win 安装需开 VT-x
- **真机**（最终推荐）：Google Pixel——"亲儿子"，可刷 AOSP、定制脱壳机，购买必须选**已解 OEM 锁的欧版**；其次小米（官方支持解 BL 锁）
- 强烈建议：买二手备用机，不要用主力机（刷机可能变砖、丢资料）

### 3.3 OEM 锁 / BL 锁

- OEM 锁即 Bootloader 锁：保护设备免受未授权修改的安全机制
- 要 root 必须先解 OEM/BL 锁；二手购买前务必确认已解锁（手机不支持解锁则自己打不开）
- Pixel 解锁教程（课件资料）：cnblogs `liuqingzheng` 的 17462146 号文章

### 3.4 Root 方式

- 目标：刷官方系统 + 基于 **Magisk 面具** root
- 小米流程：注册小米账号 → 手机与账号绑定 → 申请解 BL 锁（一般等 7 天）→ FastBoot 刷 Magisk 获得 root（FastBoot 方式一般 system 分区无法挂载）
- 风险提示：淘宝"秒解"曾有新手机被搞到无法开机又返厂的案例；代刷约 30-50 元
- 参考资料：cnblogs `liuqingzheng` 17462127（Pixel root）、magiskcn.com、B 站 `BV1er4y1C7wU`（FastBoot 刷 Magisk 视频）
- Magisk 的用途：root 权限 + 装功能模块（后续抓包要用 moveCert 把用户证书移动成系统证书）

## 四 Python 虚拟环境（day01 实操重点）

### 4.1 为什么需要

- 系统解释器全局只能装一个版本的某第三方模块；不同项目依赖版本会冲突
- 虚拟环境 = 每个项目独立解释器 + 独立依赖，互不影响，升级不污染全局
- 方案：**virtualenv**（课件主线）、pipenv

### 4.2 安装与配置

- Windows：`pip3 install virtualenv virtualenvwrapper-win`；配置 `WORKON_HOME` 环境变量指定虚拟环境存放目录（如 D:\Virtualenvs）；双击 Python 安装目录 Scripts 下的 `virtualenvwrapper.bat` 使配置生效
- macOS/Linux：`pip3 install virtualenv virtualenvwrapper`（可换豆瓣源）；找到 `virtualenvwrapper.sh`（建议放 `/usr/local/bin`）；在 `~/.bash_profile` 配置 `VIRTUALENVWRAPPER_PYTHON` 与 `source /usr/local/bin/virtualenvwrapper.sh`；`source ~/.bash_profile` 生效
- PyCharm 也可直接创建虚拟环境（课件截图演示）

### 4.3 常用命令（记住这套就够）

- `mkvirtualenv 名称` 创建（`-p python3.6` 指定解释器版本）
- `workon` 列出全部环境；`workon 名称` 进入
- `deactivate` 退出；`rmvirtualenv 名称` 删除（需先退出）
- 进入环境后直接 `pip install 模块名` 装依赖

### 4.4 项目依赖导出与恢复

- `pip freeze > requirements.txt` 导出当前环境依赖
- `pip install -r requirements.txt` 在别人机器上复现环境
- 约定：每个 Python 项目根目录必须有 requirements.txt

## 关键知识清单（速查）

- 逆向主线：APK → 反编译（dex 用 jadx/apktool；so 用 IDA）+ Hook → 读逻辑 → Python 复现
- jadx 依赖 JDK；jadx-gui 打开 apk 搜关键字（如 patriarchLogin）找算法入口
- Hook 三件套：Xposed / Frida / DLL 注入；逆向 Hook 目的 = 看参数与返回值确认逻辑
- 真机 root 前提：解 OEM/BL 锁 → FastBoot 刷 Magisk；模拟器选雷电 3 不选 4
- Pixel 为逆向推荐机型（可刷 AOSP/脱壳机），必须买已解 OEM 锁版本；华为机型不支持 root
- 虚拟环境：virtualenvwrapper 一套（mkvirtualenv / workon / deactivate / rmvirtualenv），WORKON_HOME 指定存放目录
- 依赖管理：pip freeze 导出 / pip install -r 恢复
- 参考资料：cnblogs liuqingzheng（Pixel 解锁与 root）、magiskcn.com、B 站 BV1er4y1C7wU（FastBoot 刷 Magisk）
