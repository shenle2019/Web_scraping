## 一、字节、字符、字符串的粒度关系

课件的推导链条（理解了这一层，后面所有编码问题都顺）：

- **字节**：1 byte = 8 bit，能表示 256 种变化，英文里的 `1`、`,`、`?`、`a` 一个字节就够存。
- **字符**：各国符号不同，`中`、`a`、`?`、`？` 混在一起，一个字节装不下，必须多个字节表示一个字符。
  - GBK：**2 个字节**表示一个中文
  - UTF-8：**3 个字节**表示一个中文
- **字符串**：一串字符。

课件 imgs 里放了一张完整 ASCII 表（十进制 0~127 与字符、控制符的对照），看 `byte` 和 `char` 的换算关系时直接查这张表，比记代码快。

### 把一个 byte 打印成"看得见的字符"

`System.out.println(byte)` 打印的是**数字**（ASCII 码对应的十进制）。想看字符形态有两条路：

1. 先强转 `(char)b` 得到字符，再 `Character.toString(character)` 转成字符串
2. 直接 `System.out.printf("%c", b)`

`byte b = '8';` 打印出来是 56（字符 `'8'` 的 ASCII 码），不是 `8`。这是读反编译代码时判断"这个字节到底当数字用还是当字符用"的关键——`printf("%c")` 这种写法就是明确的"当字符看"信号。

## 二、String 与 byte[] / char[] 的双向转换（day07 版本）

### byte[] → String

```java
byte[] b = new byte[]{'a', 97, -27, -67, -83, -28, -70, -114, -26, -103, -113};
System.out.println(new String(b));   // 默认按 UTF-8 解释，注意字节数组里可以直接写字面量 'a'
```

两个要点：

- 字节数组里**可以混着写字面量和数字**：`'a'` 就是 97，两种写法等价。
- 转 GBK 可能失败（字节序列不合法时抛异常），所以要么 `try-catch`，要么在方法签名上 `throws Exception`。课件给了两种写法，Demo004 用的是 try-catch 包住 GBK 那段。

### String → byte[]

```java
String s = "彭于晏";
byte[] b1 = s.getBytes();        // 平台默认编码，课件机上是 UTF-8
byte[] b2 = s.getBytes("GBK");   // 显式指定
System.out.println(Arrays.toString(b1));   // 必须用 Arrays.toString 才看得到内容
```

### String ↔ char[]

```java
char[] c = new char[]{'彭', '于', '盐'};
String v = new String(c);          // 字符数组 → 字符串

String v1 = "彭于盐";
char[] c1 = v1.toCharArray();      // 字符串 → 字符数组
System.out.println(c1.length);     // 长度
System.out.println(c1[0]);         // 按下标取
```

`char[]` 记录的是**字符个数**（`"彭于盐"` 长度 3），`byte[]` 记录的是**字节个数**（UTF-8 下 9 个）。同一个汉字两种容器下的"长度"完全不同，这是读加密代码时算长度、算偏移最容易出错的地方。

### 拼接与类型识别

- `+` 拼接：每次产生新 String，效率低，基本不用。
- `StringBuilder`（非线程安全，快）/ `StringBuffer`（线程安全，多线程追加不会错乱）。
- `sb` **不是 String 类型**，只是 `println` 内部调了 `toString()` 才看着像字符串。要真字符串必须 `sb.toString()`；`sb.getClass()` 打印的是 `class java.lang.StringBuilder`。读反编译代码时，`StringBuilder` 出现在返回值位置，往往后面跟着 `.toString()`。

## 三、python 侧对照与两个脚本

### `day07\1-python字符串和字节.py`

做三件事，全是"给字节换显示方式"，方便和 Java 打印结果对比：

- `'彭于晏'.encode('utf-8')` → `b'\xe5\xbd\xad\xe4\xba\x8e\xe6\x99\x8f'`，**默认以十六进制显示**，不是数字串
- `.encode('gbk')` → `b'\xc5\xed\xd3\xda\xea\xcc'`，两个字节一个字符
- 用列表推导把字节转成**十进制列表** `[229, 189, 173, ...]`、**二进制** `bin()`、**十六进制** `hex()`

这份脚本的重点是"python 打印的字节是十六进制，java 打印的字节数组是十进制（而且带负号）"，两边对照时先统一进制再比。

### `day07\2-把java字节数组转python字符串.py`

只有十几行，但是整篇里最值得记住的一段：

```python
v1 = [-27, -67, -83, -28, -70, -114, -26, -103, -113]   # 从 Java 侧捞出来的 byte[]

def java_arr_to_python_str(v1):
    buf = bytearray()
    for i in v1:
        if i < 0:
            i += 256
        buf.append(i)
    return buf.decode('utf-8')
```

对照关系（课件给了两组数）：

```
python: [229, 189, 173, 228, 186, 142, 230, 153, 143]    无符号 0~255
java  : [-27, -67, -83, -28, -70, -114, -26, -103, -113]  有符号 -128~127
```

**规则：正数不动，负数 +256。** 这条不处理，后面任何 `decode` / Base64 / AES 都会歪。

## 四、Object 类：一切类型的公共父类

### 根类地位

`Object` 在 `java.lang` 包下，该包所有类**自动导入**，不用手写 import。任何一个类如果没有明确写继承，它的父类就是 Object：

```java
class Person { }                  // 完全等价于
class Person extends Object { }
```

### Object 可以接收任何类型的值

Java 是强类型语言，不同类型不能互相赋值；但由于**所有类都继承 Object**，任何值都能赋给 Object 变量：

```java
Object obj;
obj = '刘';          // char
obj = "xxx";        // String
obj = 1;            // int（自动装箱成 Integer）
obj = new Person(); // 自定义对象
```

甚至可以声明 `Object[]` 数组，往里面混装字符串、数字和对象——这是 Java 里**唯一**能"混放"的容器形态（普通数组要求元素类型严格一致）。反编译里看到 `Object` 或 `Object[]` 返回值，通常意味着"这个方法返回的东西类型不确定，调用方会自己做判断和强转"。

### 代价：具体类型的方法没了

赋值给 Object 之后，原类型的方法就调不到了，只能调 Object 自己的方法。要还原类型有两条路：

- `obj.getClass()` → 打印 `class java.lang.String`、`class Person`、`class java.lang.Integer` 等
- `obj instanceof String` 判断后再强转 `(String) obj`

这就是反编译里 `if (x instanceof Xxx)` + `(Xxx) x` 这种组合的来源。

### Object 的方法清单

| 方法 | 说明 |
|---|---|
| `clone()` | protected，浅复制；必须实现 `Cloneable` 接口才允许调用，否则抛 `CloneNotSupportedException` |
| `getClass()` | final，返回 Class 对象，反射的入口 |
| `toString()` | 打印对象时默认调用，子类一般会重写 |
| `finalize()` | 释放资源用，调用时机不确定，很少用 |
| `equals()` | 比较对象**内容**是否相等 |
| `hashCode()` | 哈希查找用；重写 equals 一般要一并重写 hashCode |
| `wait()` / `notify()` / `notifyAll()` | 线程等待 / 唤醒单个 / 唤醒全部 |

最常用的是 `getClass()`、`toString()`、`hashCode()`。

**toString 的实际意义**：`println(对象)` 打出来的是什么，完全由 `toString()` 决定。Demo006 里 `Person` 重写了 `toString()` 返回 `"彭于晏"`，于是打印这个对象就输出这三个字——反编译时看到某个类里只有一个孤零零的 `toString()`，就能猜到它是为了定制日志/输出格式。

## 五、容器之 List：ArrayList 与 LinkedList

### 接口与实现的关系

List 是**接口**，ArrayList 和 LinkedList 是它的两个实现：

- `ArrayList`：底层连续内存（数组），内部自动扩容 → 对应 python list 的特点
- `LinkedList`：底层链表
- 两者使用方式几乎一样，区别在"底层数据结构不同、操作效率不同"，**ArrayList 用得最多**

接口本身只是"规定子类必须实现哪些行为"：

```java
interface Duck { void speak(); void run(); }
class TDuck implements Duck {   // 实现接口，必须重写接口里所有方法
    public void speak() { }
    public void run() { }
}
```

### 泛型：写不写 `<String>` 的差别

```java
ArrayList arr = new ArrayList();              // 不写 = 元素都是 Object，什么都能放，用得少
ArrayList<String> names = new ArrayList<String>();  // 指定类型，只能放 String，用得多
```

### 和数组的区别（Demo007 里的注释点）

- 数组：**定长**，不能追加、不能删除，也不能判断某元素是否存在
- ArrayList：可以 add / remove / contains，类似 js 的数组、python 的 list

### List 常用操作

| 操作 | 写法 |
|---|---|
| 追加 | `add(值)` |
| 按索引取 | `get(下标)` |
| 改某个位置 | `set(下标, 新值)` |
| 删（按值） | `remove("迪丽热巴")` |
| 删（按下标） | `remove(0)` |
| 长度 | `size()`（**不是 length**） |
| 是否包含 | `contains(值)` |
| 下标循环 | `for (int i = 0; i < list.size(); i++) list.get(i)` |
| 增强 for | `for (String item : list)` |

LinkedList 额外有一组队首队尾操作：`push("xxx")`（放首位，等价 addFirst）、`addFirst(...)`、`addLast(...)`。

### 迭代器

```java
Iterator i = names.iterator();
while (i.hasNext()) {
    System.out.println(i.next());
}
```

对应 python 的迭代器协议。反编译里 `Iterator` + `while (hasNext()) next()` 是 for-each 被展开后的常见形态。

## 六、容器之 Set：去重集合

Set 也是接口，两个常见实现：

- **HashSet**：去重，**无序**
- **TreeSet**：去重，**内部自动排序**（按 ascii / unicode）；不同类型的数据无法互相比较，所以 TreeSet 里只能放同一类型

### 常用操作

`add`（重复值加不进去）、`contains`、`remove`、`size`，遍历用增强 for 或 Iterator。

### 交并差（重点：都会直接改调用者集合）

```java
HashSet<String> h3 = new HashSet<String>();
h3.addAll(h2);      // 把 h2 全部并进 h3 —— 并集
h3.retainAll(h1);   // 只保留与 h1 共有的 —— 交集，结果 [Justin]
h2.addAll(h1);      // 再并一次
h2.removeAll(h1);   // 从 h2 里去掉 h1 的元素 —— 差集，结果 [杨颖, 迪丽热巴, 古力娜扎, 刘亦菲]
```

这组方法**没有一个会返回新集合**，全部在调用者身上原地生效。逆向时如果看到 `retainAll` / `removeAll`，基本可以判断这段在算签名参数集合、白名单过滤之类的逻辑。

## 七、容器之 Map：键值对

Map 是接口，两个常见实现：

- **HashMap**：无序
- **TreeMap**：按 **key** 排序（课件标"常用"），对应 python 的 dict

### 常用操作

| 操作 | 写法 |
|---|---|
| 存 | `put("name", "lqz")`，同一个 key 再 put 会**覆盖** |
| 取 | `get("name")` |
| 删 | `remove("name")` |
| 长度 | `size()` |
| 判 key | `containsKey("name")` |
| 判 value | `containsValue("篮球")` |
| 替换 | `replace("age", "99")` |

### 三种遍历（读反编译代码必认）

```java
// 方式一：keySet
for (String key : hm.keySet()) { hm.get(key); }

// 方式二：entrySet + 增强 for
for (Map.Entry<String, String> item : hm.entrySet()) {
    item.getKey();
    item.getValue();
}

// 方式三：entrySet → Set → Iterator → 强转（案例里会出现这种）
Set s2 = hm.entrySet();
Iterator it2 = s2.iterator();
while (it2.hasNext()) {
    Map.Entry entry = (Map.Entry) it2.next();
    (String) entry.getKey();
    (String) entry.getValue();
}
```

方式三是 jadx 里最常出现、也最不好读的形态：`Map.Entry` 强转 + getKey/getValue。看到这套结构就是在遍历 Map。

## 八、面向对象基础

### 类与对象

- 现实世界：先有对象（泰迪 1 号、泰迪 2 号），归纳出类（泰迪狗类）
- 程序里：**先定义类，再实例化得到对象**

### 构造方法 ≈ python 的 `__init__`

```java
class Dog {
    String name;
    int age;

    public Dog(String name, int age) {
        this.name = name;   // this ≈ python 的 self
        this.age = age;
    }

    public void speak() {
        System.out.println("狗叫");
    }
}
```

三条硬性约束：**必须是 public、不能有返回值、方法名必须与类名相同**。`this` 指当前对象；未在类里声明的属性，`this.` 也拿不到。

### 方法重载（overload）

同一个类里**同名不同参数列表**：

```java
public void speak() { }
public void speak(String s) { }
```

课件把构造方法也写成两个版本（无参 / 带参），这就是典型的构造方法重载。**重载的存在是 Hook 时必须写 `overload(...)` 的唯一原因**——方法名相同，只能靠参数签名区分。

### static 成员

```java
class Person {
    public static String school;   // 静态变量，属于类
    public static void run() { }
}

p.school = "清华大学";
Person.school = "北京大学";   // 两者指向同一份，最终都是"北京大学"
```

静态成员属于**类**而非对象：实例能访问、类名也能访问，但数据只有一份。所以 `p.school` 改完再打印 `Person.school`，值是最后赋的那个。

### 继承与接口

- `class Person extends Foo { }`：Java **只支持单继承**，不能 `extends A, B`
- `class Person implements Base, Foo { }`：**接口可以实现多个**，必须重写所有接口方法（配合 `@Override`）

一句话：**单继承、多实现**。反编译里看到一大串 `implements XxxListener, YyyCallback` 就是在补足单继承的限制。

## 九、逆向落点：Frida Hook 重载方法与构造方法

这一节是本篇对逆向最直接的价值，两个脚本都在 hook `油联合伙人`（`rdev.attach("油联合伙人")`，中文进程名可以直接 attach）。

环境前置（脚本头部注释）：手机端 `su` → `cd /data/local/tmp/` → 启动 `frida-server-16.0.19-android-arm64`；电脑端 `adb forward tcp:27042 tcp:27042` 与 `27043` 一起转发。

### Hook 重载方法：按参数签名指定

```js
var MessageDigest = Java.use("java.security.MessageDigest");

MessageDigest.update.overload('[B').implementation = function(data){ ... }
MessageDigest.update.overload('java.nio.ByteBuffer').implementation = function(data){ ... }
```

关键点：

- `overload('参数类型')` 用来在**同名方法**里挑具体那一个。不写 overload 会报错（frida 不知道你要 hook 哪个）。
- `'[B'` 是 JVM 的类型描述符，`[` 表示数组、`B` 表示 byte —— 合起来就是 **`byte[]`**。常见的还有 `'[C'`(char[])、`'[Ljava.lang.String;'`(String[])、`'int'`、`'java.lang.String'`。
- `MessageDigest.update` 是 **void 方法**，课件脚本里 `var res = this.update(data); return res;` 属于照模板抄的写法，取返回值和 return 都没实际意义；更要紧的是这个脚本里**没有任何 `console.log`**，所以它只能证明"挂上了"，看不到入参。真要看数据得自己在 `implementation` 里打印 `data`（字节数组还要按第四节的办法 +256 转成 python 能读的形态）。

### Hook 构造方法：`$init`

```js
var StringBuilder = Java.use("java.lang.StringBuilder");

StringBuilder.$init.overload('int').implementation = function(num){
    console.log(num);
    if (num == 32) {
        var res = this.$init(num);
    }
    return res;
}
```

要点：

- Java 构造方法在 frida 里没有方法名，统一用 **`$init`** 表示；`overload('int')` 对应 `StringBuilder(int capacity)` 这个重载。
- `num == 32` 这个判断说明课件的目的是**只拦容量为 32 的 StringBuilder**——加密函数里 `new StringBuilder(32)` 往往是拼签名的起手式，命中它就能顺着找上层调用。
- 坑：`res` 在 if 之外 return，`num != 32` 时 `res` 未定义；而且**不调用 `this.$init(...)` 就不会执行原始构造逻辑**，对象会处于未初始化状态，后续调用可能崩。正确姿势是无论走哪个分支都要调用一次原方法（或在条件外兜底调用）。

## 十一、关键知识清单

- 1 字节 256 种变化只够英文；GBK 一个中文 2 字节，UTF-8 一个中文 3 字节。
- `println(byte)` 打数字、`printf("%c", byte)` 打字符；`(char)` + `Character.toString` 是另一条路。
- 字节数组里可以混写 `'a'` 和 `97`，两者等价。
- `char[]` 的 length 是字符数，`byte[]` 的 length 是字节数，同一串汉字两种容器下长度不同。
- **Java byte 有符号、Python bytes 无符号，负数 +256 才能对齐**；这是 `java_arr_to_python_str()` 的全部逻辑。
- `getBytes()` / `new String(byte[])` 不带编码时依赖平台默认编码，逆向复现一律显式写 UTF-8 / GBK；GBK 转换要处理异常。
- `sb` 不是 String，`println` 能打印是因为内部调 `toString()`；`StringBuilder` 快、`StringBuffer` 线程安全。
- **Object 是所有类的父类**，`class A {}` 等价 `class A extends Object {}`；`java.lang` 包自动导入。
- Object 变量能接任何类型，`Object[]` 是 Java 里唯一能混装不同元素类型的容器。
- 赋值给 Object 后原类型方法丢失，要 `getClass()` 或 `instanceof` 判断后强转回来。
- Object 方法里最常用 `getClass()` / `toString()` / `hashCode()`；重写 `toString()` 就定制了打印内容。
- **List**：ArrayList（数组、自动扩容、最常用）/ LinkedList（链表）；`add/get/set/remove/size/contains`，长度是 `size()` 不是 `length`。
- LinkedList 额外有 `push`（放首位）/`addFirst`/`addLast`；List 与数组的区别是**可增删、可判断存在**。
- 接口 `implements` 必须重写全部方法；泛型不写就是 Object，什么都能放。
- **Set**：HashSet 去重无序，TreeSet 去重且按 ascii/unicode 排序（同类元素才可比）。
- `addAll` 并集、`retainAll` 交集、`removeAll` 差集，**三者都原地修改调用者集合，不返回新集合**。
- **Map**：HashMap 无序、TreeMap 按 key 排序；`put` 同 key 覆盖；三种遍历里 `entrySet` + `Iterator` + 强转 `Map.Entry` 是 jadx 里最常见、最不好读的那种。
- 构造方法必须 public、无返回值、与类同名；`this` ≈ python 的 `self`；构造方法可以重载。
- 方法重载 = 同名不同参数列表，**这正是 Frida hook 必须写 `overload(...)` 的原因**。
- `static` 成员属于类，实例和类名访问的是同一份数据。
- **单继承、多实现**：`extends` 只能一个，`implements` 可以多个。
- **Hook 重载方法**：`Cls.method.overload('[B')`，`[B` = byte[]；不写 overload 会报错。
- **Hook 构造方法**：用 `$init`，`overload('int')` 对应 `StringBuilder(int)`；条件分支里不调用原 `$init` 会让对象未初始化。
