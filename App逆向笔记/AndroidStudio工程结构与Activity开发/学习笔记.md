## 一、Java 常见加密方式（开篇回顾）

这一节和 day08 的加密编码篇同源（连截图都是同一批），只留速查表，机制细节见 `Java面向对象与常用加密编码` 那份笔记。

| 项 | Java 侧 | Python 侧 | 要记的点 |
|---|---|---|---|
| 字节 ↔ 字符串 | `Arrays.toString(s.getBytes())`、`new String(new byte[]{115,...})` | `java_arr_to_python_str`：负数 +256 | hook 到的 byte[] 先还原成字符串 |
| UUID | `UUID.randomUUID().toString()` | `str(uuid.uuid4())` | 8-4-4-4-12 共 36 字符，常当设备/请求唯一 id |
| 随机值 | `new BigInteger(80, new SecureRandom()).toString(16)` | `random.randbytes(10)` 逐字节取 hex | 80 位 = 10 字节；`toString(16)` 可能带负号 |
| 时间戳 | `System.currentTimeMillis()` | `int(time.time()*1000)` | 除以 1000 得秒级 |
| 字节转 hex | 循环 `& 0xFF` + `Integer.toHexString` | `hex(i)[2:].rjust(2,'0')` | 不足两位补 0，`hex()[2:]` 会吃前导零 |
| MD5 | `MessageDigest.getInstance("MD5")` → `update` / `digest()` | `hashlib.md5().hexdigest()` | Java 没有 hexdigest，32 位 hex 要自己拼 |
| Base64 | `Base64.getEncoder().encodeToString()` / `getDecoder().decode()` | `base64.b64encode` / `b64decode` | Java 直接给 String，python 给 bytes |

本篇在这张表上没有新增算法，重点整体挪到了安卓工程本身。

## 二、开发环境：AndroidStudio + SDK + 运行环境

### 2.1 三件套与演进

- 做安卓 App 需要：**Java 语言 + Android SDK（安卓内置类库）+ 编辑器**，外加一个能跑 App 的环境。
- 早期是 Eclipse 自己搭 SDK；现在 Google 直接给 AndroidStudio（JetBrains 版权，操作手感接近 PyCharm），安装完自带 SDK。
- 运行环境三条路：**真机**（开 USB 调试即可，不用 root，课件推荐）、第三方模拟器（mumu、夜神）、AS 自带模拟器（课件原话：讲完就忘）。
- 背景补充（课堂笔记）：安卓 App 正常从谷歌市场分发，国内访问不了；安卓开源，各家能改出自己的系统（小米 MIUI 等）；华为鸿蒙老版本兼容 apk，新版本是独立应用格式，安卓 apk 跑不了。

### 2.2 下载与安装

- 历史版本 `developer.android.google.cn/studio/archive`，最新版 `.../studio`，官方入门教程 `.../studio/intro`。
- 安装一路下一步：注意是否勾选安装模拟器（用真机就不装）、注意安装路径。

### 2.3 构建工具：Gradle vs Maven

| 维度 | Gradle | Maven |
|---|---|---|
| 脚本语法 | Groovy（灵活、像代码） | XML（严谨、易复用） |
| 性能 | 增量构建，只重编改动模块 | 整体重新构建 |
| 插件 | 生态新，好写好改 | 传统，配置繁琐 |
| 维护 | 相对新，要自学 | 工具链和文档成熟 |

- **安卓工程用的是 Gradle**，Java Web 侧 Maven 更常见。
- Groovy 是跑在 JVM 上的敏捷语言，吸收了 Python/Ruby/Smalltalk 的特性，能和 Java 互相调用——所以 `build.gradle` 长得像配置又像代码。

### 2.4 SDK 配置

- Settings → Appearance & Behavior → System Settings → Android SDK，SDK Location 指到 `D:\sdk`。
- **SDK Platforms** 装的是安卓版本。"大名"和"小名"（API Level）的对应：安卓 11 = 30、安卓 13 = 33、安卓 14 = 34。截图里装了最新的 34，另勾了手机对应的 30。
- **SDK Tools** 是工具：Build-Tools、Platform-Tools（adb 等工具就在这里）、Android Emulator、Google USB Driver（谷歌驱动）。截图里 NDK / CMake / Command-line Tools 被框出来标注"做 JNI 开发需要"——今天不装，等 day13 的 JNI 才用。
- **环境变量**：把 SDK 目录下的 `emulator`、`platform-tools` 加进 Path。`platform-tools` 就是 adb 所在目录，day02 一直在用的那套。

### 2.5 新建项目与首次同步

- New Project → Phone and Tablet → **Empty Views Activity**（选空页面）。
- 创建后 AS 会做 Gradle sync，第一次要下载 `gradle-8.0-bin.zip`（约 124MB），进度条停在 "Gradle: Download gradle-8.0-bin.zip" 很久是正常现象。
- 截图里还演示了把左上角 `Android` 视图切成 `Project` 视图——这一步是看懂磁盘结构的前提。

### 2.6 真机 / 模拟器运行

- 真机：开发者模式 + USB 调试 → 插线 → 手机上点授权 → AS 设备列表出现机型；不出现就"撤销 USB 调试授权"再重插。

## 三、工程结构：两个视图

### 3.1 安卓视图（开发时看）

截图注解把这块讲清了，只关注四块：

| 位置 | 管什么 |
|---|---|
| `manifests` | 项目名、图标、启动哪个页面、权限配置 |
| `java` → `com.justin.s12day09` | 一个页面就有一个 `*Activity`，业务逻辑都在 `onCreate` 及其调用链里 |
| `res` | 资源：`layout` 页面布局 xml、`drawable` 图片、`values` 颜色/字符/主题、`mipmap` 图标 |
| `Gradle Scripts` | 构建配置与依赖 |

### 3.2 项目视图（磁盘真实结构）

```text
app
├── src/main/java/com.justin.s12day09/   # 代码，一个页面一个 Activity
├── src/main/res/                        # 资源
│   ├── drawable/    # 图片（a/b/c.jpg）
│   ├── layout/      # 页面布局 xml
│   ├── mipmap*/     # 桌面图标（按屏幕密度多套）
│   ├── values/      # colors / strings / themes
│   └── xml/         # security.xml 这类配置
├── src/main/AndroidManifest.xml         # 入口、权限、主题、图标
├── build.gradle                         # Module 级：依赖与编译参数
├── proguard-rules.pro                   # 混淆规则
└── build/                               # 编译产物，可整个删
build.gradle / settings.gradle / gradle.properties / local.properties / gradlew*
```

几个容易混的点：

- **两个 `build.gradle`**：根目录的叫 Project 级（仓库、插件版本），`app\build.gradle` 叫 Module 级（依赖、SDK 版本、签名），写依赖永远写进 Module 级那份。
- `local.properties` 只是本机 SDK 路径，一般不提交。
- `app\build\` 是产物目录，编译报怪问题时删掉重来是常规操作。
- `.gradle`、`.idea` 都是 IDE 自动维护的，不进版本库。

### 3.3 逆向视角的对应关系

- jadx 里的类全名 = `java\` 下的包路径 + 类名：`com.justin.s12day09.MainActivity` 对应磁盘上的 `com/justin/s12day09/MainActivity`。
- `R.id.*`、`R.drawable.*`、`R.layout.*` 都是编译期生成的资源索引（R 类）。第三方包里 R 类常被裁掉，资源 id 直接变成一串数字——这就是为什么反编译代码里常看到 `findViewById(2131230720)` 这种硬编码数字。
- `AndroidManifest.xml` 里带 `intent-filter` + `MAIN`/`LAUNCHER` 的那个 Activity 就是 App 入口。**逆向上手第一件事：在 Manifest 找 LAUNCHER Activity，再顺着它的 `onCreate` 往下摸。**

## 四、开发流程：正向与逆向对照

课件那张流程图值得单独记：

- 上半部分（安卓正向开发）：AndroidStudio 里的 app = xml 页面 + java 业务逻辑 → 发请求 → 后端服务（python 侧 flask/django/fastapi/sanic，go 侧 gin/beego，java 的 SpringBoot，还有 php、nodejs）。

## 五、第一个 App：点按钮换图

### 5.1 布局 `activity_main.xml`

- 根 `LinearLayout`，里面再套一层 `LinearLayout`（`orientation="vertical"`，背景 `#AEEEEE`）。
- `ImageView`：`android:id="@+id/image"`、高 `300dp`、初始 `android:src="@color/pink"`（先用纯色占位）。
- `Button`：`android:id="@+id/button01"`、`text="点击切换美女"`、字号 23dp、文字色 `@color/green`。
- id 语法：**`@+id/xxx` 是新建并登记到 R.id，`@id/xxx` 是引用已有 id**。`dp` 是密度无关的尺寸单位，不是像素。
- `pink` / `green` 两个颜色要自己在 `res\values\colors.xml` 里补，否则 `@color/pink` 直接编译报错。

### 5.2 放图片

三张图丢进 `app\src\main\res\drawable\`，命名 `a.jpg` / `b.jpg` / `c.jpg`，代码里就是 `R.drawable.a`——文件名即资源名，不能带大写、不能数字开头。

### 5.3 `MainActivity.java` 的四步骨架

1. `extends AppCompatActivity`，重写 `onCreate(Bundle savedInstanceState)`，第一行 `super.onCreate(...)`；
2. `setContentView(R.layout.activity_main)` —— **把 java 类和 xml 布局绑在一起**，页面一打开就走这里；
3. `findViewById(R.id.image)` / `findViewById(R.id.button01)` 拿到控件对象；
4. `btn.setOnClickListener(new View.OnClickListener(){ onClick(...) })` 绑点击，里面 `Toast.makeText(...).show()` 弹提示、`image.setImageResource(id)` 换图。

细节：

- 成员变量 `private int id = R.drawable.a;` 记当前显示哪张，点击时按 a→b→c→a 循环。
- 匿名内部类里要用 `MainActivity.this` 指外部 Activity（那时 `this` 指 `OnClickListener` 自己）。
- 课件源码里留了一句改进思路注释：用 ArrayList 放 100 张图、每次 random 取一张。
- 运行效果截图：顶部一张图 + 底部"点击更换美女"按钮，点一次换一张并弹 Toast。

## 六、加载网络图片

三条前提：手机能上网、**代理关掉**、`AndroidManifest.xml` 加 `INTERNET` 权限。

代码骨架（这份来自另一个工程 s9demo01，控件 id 叫 `button`）：

- 点击 → `new URL("https://...")` → `requestImage(url)`；
- `new Thread(){ run(){ bitmap = BitmapFactory.decodeStream(url.openStream()); showImg(); } }.start()` —— **网络请求必须开子线程**；
- `showImg()` 里 `runOnUiThread(new Runnable(){ image.setImageBitmap(bitmap) })` —— **UI 只能在主线程改**。

坑：

- 主线程做网络会抛 `NetworkOnMainThreadException`（安卓 3.0 起）。
- `url.openStream()` 是同步阻塞的，线程没起就是卡界面。
- 没有缓存、没有占位图、没有异常兜底，是最原始的教学写法；真实 App 用 Glide / OkHttp。
- 明文 http 从 Android 9 起默认禁止，https 才能直接请求（下面的登录案例要单独开洞）。

## 七、登录案例：布局 + OkHttp + Flask

### 7.1 布局

- 外层 `LinearLayout` 撑满，内层灰色卡片 `#dddddd`、`layout_marginTop="150dp"`、高 216dp。
- 标题 `TextView`（`textAlignment="center"`、25dp）；两行 `TextView + EditText`，密码框加 `android:inputType="textPassword"`；两个 Button「登录」「重置」。
- 截图给的是设计视图 + 蓝图视图对照，能看清控件层级和间距。

### 7.2 java 逻辑

- `initView()`：`findViewById` 四个控件（`txt_user`、`txt_pwd`、`btn_login`、`btn_reset`），拆成两个初始化方法是课堂习惯。
- `initListener()`：重置清空两个输入框；登录按钮调 `loginForm()`。
- `loginForm()`：
  - `String.valueOf(txtUser.getText())` 取输入（`getText()` 返回的是 Editable，不是 String）；
  - 先建好 Toast 对象 `Toast t = Toast.makeText(MainActivity.this, "登录成功", Toast.LENGTH_SHORT)`；
  - `new Thread(){...}` 里走 OkHttp：`new OkHttpClient.Builder().build()` → `new FormBody.Builder().add("user", ...).add("pwd", ...)` → `new Request.Builder().url("http://192.168.1.12:8080/login").post(form)` → `client.newCall(req).execute()` → `res.body().string()`；
  - 回来之后 `t.show()` + `Log.e("请求发送成功", dataString)`。
- 线程处理和上一篇的网络图片案例不一致：那边用 `runOnUiThread` 回主线程，这边直接在子线程 `t.show()`。Toast 和直接改 View 不是一回事，但这种混写说明课件对线程约束没较真，自己写时统一回主线程更稳。

### 7.3 三处配置（少一个都发不出去）

| 位置 | 加什么 |
|---|---|
| `app/build.gradle` | `implementation "com.squareup.okhttp3:okhttp:4.9.1"` |
| `AndroidManifest.xml` | `<uses-permission android:name="android.permission.INTERNET"/>` |
| `res/xml/security.xml` + `<application>` | `<base-config cleartextTrafficPermitted="true"/>`，并在 application 标签上挂 `android:networkSecurityConfig="@xml/security"` |

课件第 3 步只写了"在 AndroidManifest.xml 加入"、没写出属性名。实际生效靠的是 `<application android:networkSecurityConfig="@xml/security">` 这一行——只建 `security.xml` 不引用是没用的。

### 7.4 Flask 后端

- `/login` POST，`request.form.get('username')` / `'password'`，等于 justin/123 就回一个 uuid 当 token。
- `app.run('0.0.0.0', 8080)`：只有 `0.0.0.0` 才能让同局域网的手机访问，写 `127.0.0.1` 手机连不上。
- URL 里的 `192.168.1.12` 是老师电脑的局域网 IP，自己跑要换成自己电脑的（`ipconfig` 查）。
- **坑：两端字段名不一致**。app 里 `FormBody` 发的是 `user` / `pwd`，Flask 读的却是 `username` / `password`，照抄会永远走"用户名或密码错误"分支。联调第一步永远是对齐 key。
- 另一个小疏漏：成功和失败都返回 `code: 100`，客户端没法靠 code 区分。

## 八、打包 APK 与反编译自己的 App

### 8.1 打包

- 菜单 Build → **Build Bundle(s) / APK(s) → Build APK(s)**。
- 产物在 `app\build\outputs\apk\debug\app-debug.apk`，旁边还有一个 `output-metadata.json`。
- 课堂工程的实际配置：`namespace` / `applicationId` 都是 `com.justin.s12day09`、compileSdk 33、minSdk 29、targetSdk 33；依赖只有 appcompat 1.4.1、material 1.5.0、constraintlayout 2.1.3——这个 demo 没引 okhttp。
- Manifest 里启动 Activity 写着 `android:exported="true"`：targetSdk 31 起，带 intent-filter 的组件必须显式声明 exported，否则装不上。

### 8.2 jadx 打开自己写的 apk

反编译结果和源码的差异，这一节最值得记：

| 现象 | 原因 |
|---|---|
| `/* Loaded from: classes3.dex */` | 多 dex 打包，类被分散到 classes、classes2、classes3… |
| `com.justin.s12day09.MainActivity.1` | 源码里的匿名内部类 `new View.OnClickListener(){}` 编译成 `MainActivity$1` |
| `(Button) findViewById(...)` | 泛型擦除，反编译后必须显式强转 |
| `Toast.makeText(..., "...", 0)` | `LENGTH_SHORT` 是编译期常量，被内联成 0（`LENGTH_LONG` = 1） |
| `if (id != R.drawable.a) { if (...) {...} else {...} } else {...}` | if/else 链被还原成"条件取反 + 嵌套"，顺序和源码不一致 |
| 满屏 `MainActivity.this.id` | 匿名内部类持有外部实例引用，字段访问都带外部类前缀 |
| `/* JADX INFO: Access modifiers changed from: protected */` | 反编译器提示修饰符与源码不同，是提示不是业务逻辑 |

读法：**先分辨"编译器产物"和"业务逻辑"**。多 dex、匿名类、强转、常量内联、分支取反、`Outer.this` 前缀都是产物；真正要抄的是那段 a→b→c 的换图逻辑。

## 十、关键知识清单

- 安卓开发三件套：Java + Android SDK + 编辑器；运行环境优先真机（开 USB 调试即可，不用 root）。
- 安卓用 **Gradle**（Groovy 脚本、增量构建），Java Web 侧更多用 Maven（XML）。
- SDK Platforms 装的是安卓版本：安卓 11 = API 30、安卓 13 = 33、安卓 14 = 34；SDK Tools 里 Platform-Tools 就是 adb。
- NDK / CMake / Command-line Tools 是 JNI 开发才要（day13 用）；环境变量加 `emulator` 和 `platform-tools`。
- 首次 Gradle sync 要下 gradle 发行包（124MB），慢是正常的。
- 安卓视图只看 manifests / java / res；项目视图才是磁盘结构，`local.properties` 记 SDK 路径。
- `AndroidManifest.xml` 管图标、主题、入口、权限；带 `MAIN` + `LAUNCHER` 的 Activity 就是 App 入口。
- `@+id/xxx` 新建 id，`@id/xxx` 引用；`R.id` / `R.drawable` / `R.layout` 都是编译生成的资源索引。
- Activity 四步：`extends AppCompatActivity` → `onCreate` 里先 `super.onCreate` → `setContentView` 绑布局 → `findViewById` 拿控件 → `setOnClickListener` 绑事件。
- 匿名内部类里用 `MainActivity.this` 指外部 Activity；`dp` 是密度无关尺寸。
- 网络请求必须子线程，UI 更新必须回主线程（`runOnUiThread`）；`BitmapFactory.decodeStream(url.openStream())` 是最原始的图片加载。
- 明文 http 从 Android 9 起默认禁止：建 `res/xml/security.xml` 并在 `<application>` 上挂 `android:networkSecurityConfig`。
- OkHttp：`FormBody.Builder().add(k,v)` 发表单、`call.execute()` 同步、`body().string()` 取响应；依赖写进 `app/build.gradle`。
- Flask：`request.form.get` 接表单，`app.run('0.0.0.0', 8080)` 才能被手机访问；手机与电脑同一局域网，URL 写电脑的局域网 IP。
- 联调先对齐字段名：app 发 `user`/`pwd`、Flask 读 `username`/`password` 是课件自带的坑。
- 打包：Build → Build APK(s)，产物在 `app\build\outputs\apk\debug\app-debug.apk`；targetSdk 31+ 必须显式 `android:exported`。
- jadx 反编译差异：多 dex、匿名类 `$1`、泛型丢失产生强转、常量内联（`LENGTH_SHORT`=0）、if-else 取反嵌套、`Outer.this` 前缀。
- 逆向读代码第一原则：先把编译器产物和业务逻辑分开，再谈抄逻辑。
