## 四、代理对照（系统代理 8899）

`evidence/proxy.log`：

```
[proxy] GET http://192.168.31.220:8000/app/ping <- 192.168.31.44
```

`server.log`：

```
[16:17:04] GET /app/ping ip=192.168.31.220 ua=duapp/4.74.5(android;11)
[16:17:08] POST /getVisitorUserId ip=192.168.31.44 uuid=94c524fbc58a04e0
```

对比很清楚：

- `/app/ping` 走 `PLAIN_CLIENT`，经过 PC 代理，服务端来源是 `192.168.31.220`；
- `/getVisitorUserId` 走 `API_CLIENT`（`Proxy.NO_PROXY`），代理日志里没有它，
  服务端来源是手机真实 IP `192.168.31.44`。

截图 06 为 App 内日志。
