IDA Pro 8.3 批处理 attach 尝试记录（未打通）

一、第一次：直接在中文路径下运行
命令：
  idat64.exe -A -S test_attach.idc -L ida_test.log libutils.so
结果：ExitCode=1，未生成 .i64，IDC 脚本未执行
日志特征：88 个插件全部加载失败
  LoadLibrary(...\IDA_Pro_v8.3_Portable\plugins\dbg64.dll) error: 找不到指定的模块
  ...
  The key file is not found. -> OK
原因：课件自带说明写明“绿色版释放路径不要含有中文路径”，IDA 用 QT LoadLibrary 时对中文路径转码有问题

  The key file is not found. -> OK
插件已能加载（中文路径问题已解决），但 IDA 主程序仍直接退出，怀疑缺少授权 key
