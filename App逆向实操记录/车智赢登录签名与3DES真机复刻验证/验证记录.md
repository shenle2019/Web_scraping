## 1. 设备端 frida-server 起不来

现象：`frida-ps -U` 一直超时。

```powershell
adb shell "ps -A | grep frida"
# root 29134 1 ... fs1663        ← 一个改过名的 16.3.3 副本占着 27042
```

`kill 29134` 不生效，改用：

```powershell
adb shell "su -c 'killall -9 fs1663'"
adb shell "su -c 'setsid /data/local/tmp/frida-server &'"
adb shell "ps -A | grep frida"
# root 14042 1 ... frida-server
frida-ps -U | Select-Object -First 5
# 能列进程了
```

结论：端口被占时不要反复重启，先看 27042 归谁。

## 3. 复刻工程首次编译失败

报错点在 `SecurityUtil.java`：

```
错误: 找不到符号
符号: 变量 AHAPIHelper
```

原因：`encode3Des` 里调了 `AHAPIHelper.getDesKey(context)`，但文件没 import。补上 `import com.autohome.ahkit.AHAPIHelper;` 后：

```powershell
$env:JAVA_HOME="D:\Android\jbr"
gradle assembleDebug
# BUILD SUCCESSFUL in 9s
# app\build\outputs\apk\debug\app-debug.apk
```

`build.log` 里只剩一条无关紧要的提示：`AppUtils.java 使用或覆盖了已过时的 API`（`TelephonyManager.getDeviceId`）。
