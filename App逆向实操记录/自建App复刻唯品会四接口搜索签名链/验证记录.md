## 七、遇到的问题与解决（记录备查）

1. frida-server 多实例残留导致连不上 → killall 后单实例重启
2. Python `get_remote_device()` + spawn 超时 → 改 `frida.get_usb_device(timeout=10)`
3. `pm clear` 后 App 卡启动页、KeyInfo 类 60 秒不加载 → 不清数据正常启动，按 pidof 拿 pid attach
4. hook 日志互相覆盖/观察窗口与触发搜索时序不同步 → 一体化脚本 08_auto_hook_search.py（脚本内 subprocess 自动触发搜索）
5. 中文 adb input text 不可用 → 搜索关键字改用英文 nike（接口对语言无要求）
6. 交付目录在工作区外，Write 工具拒写 → 先写工作区 _tmp_case 再 Copy-Item
